# grok-build study: TUI perf + provider design

Source: `/tmp/grok-build` (shallow clone of xai-org/grok-build). All paths below are relative to it. Verified by direct read; subagent summaries cross-checked.

## Q1 summary — PERFORMANCE: event-driven, dirty-flag, throttled rendering

No fixed-FPS loop. A `Presenter` coalesces draw requests behind a dirty flag, an in-flight-frame gate, and a min-draw-interval throttle (default 16ms ≈ 60fps cap). A dedicated writer thread owns blocking terminal writes so slow terminals stall only the writer, never the event loop. Scrollback is a virtualized item list (`ListPaneState`: stable IDs, per-width height cache, visible-map) with follow-mode; wheel/keyboard scroll dispatches `Action::ScrollUp/Down(n)` against in-app state — no tmux copy-mode. Streaming output arrives as ACP/session events on tokio channels and is folded into state changes that only *request* (throttled) draws.

## Q2 summary — AGENT ABSTRACTION: no provider trait; swap = model catalog + wire-protocol enum + auth

There is no `Provider`/`Agent` swap trait. Model choice is data: `xai-grok-models/default_models.json` + `SamplingConfig` (`xai-grok-sampling-types`) carried per session, with precedence CLI flag → env → config.toml → remote settings → compiled defaults. The sampler speaks HTTP directly (xAI Responses / ChatCompletions / Anthropic Messages via `ApiBackend` enum) — it never shells out to CLIs. `xai-acp-lib` is an in-process ACP message bus (tokio mpsc channels + gateways), not a subprocess protocol. Extensibility hooks are lifecycle *contributor* traits (`TurnLifecycleContributor` et al.), not provider traits. For polyforge (which shells to `muse serve` over JSON-RPC), the directly reusable idea is the `SamplingConfig`-style per-session model binding + `ApiBackend`-style enum — not the contributor system.

## Details — performance

- Render loop: `Presenter` (`crates/codegen/xai-grok-pager/src/app/event_loop.rs:497`) holds `dirty`, `force_full_repaint`, `in_flight_target`, `last_draw_at`/`draw_scheduled_at`. `try_present` (`:574`) skips unless dirty AND no frame in flight AND writer drained (`written >= queued_before`); `request_throttled` (`:605`) defers to `last_draw_at + min_draw_interval`.
- Cadence numbers: `DISPLAY_REFRESH_DEFAULT_CADENCE_MS = 16` (`crates/codegen/xai-grok-shell/src/util/config/resolve/display_refresh.rs:12`); env knobs `GROK_MIN_DRAW_MS`, `GROK_SCROLL_CADENCE_MS` clamped to 1..=100ms (`.../xai-grok-pager/src/app/display_refresh_startup.rs:14`); pinned at startup into `MotionClocks { min_draw_interval, scroll_cadence }` (`:18`). Display-refresh probe can auto-tune cadence to measured Hz; telemetry runs on `spawn_blocking`, off the paint path.
- Anti-starvation: state-change arm caps paint rate "so terminal input isn't starved during heavy ACP streaming" (`event_loop.rs:2254-2263`); a 128-slot channel is serviced last so voice events "can never starve cancellation, ACP, … keyboard input" (`:2923-2926`). Stall flush path exists for blocked writers (`finish_run_with_stall_flush`, `:2246`).
- Writer thread: frame bytes are buffered and handed to a writer thread for the blocking stderr/pty write — "only the writer thread stalls; the event loop keeps processing timers, events, and ACP messages" (`crates/codegen/xai-grok-pager-render/src/render/draw.rs:150`). `EscapeWriter` (`draw.rs:245`) is the queue-riding handle; `TermWriter::escape_writer` (`:220`) is the live handle (`disconnected()` is headless/test-only, `:256`). Blocked-writer report after `WRITER_BLOCKED_WARN_AFTER = 5s` (`event_loop.rs:484`).
- Scrollback viewport: `ListPaneState` (`crates/codegen/xai-grok-pager/src/views/list_pane/state/methods.rs:11`) stores `scroll_offset`, `viewport_height`, `selected_id` (stable u64, index resolved in `prepare_layout`), `height_cache` + `height_cache_width` (rebuilt on width change, `:473`), `vis_map` (visible→physical map, `:127-145`), `ListLayoutCache::fixed` with `virtual_y` (`:345`), `follow_mode`, `scroll_margin: 2`, `overscroll_ticks`. Render reads only the visible window (`views/list_pane/render.rs:503` checks `follow_mode`).
- Wrapping: word-aware, style-span-preserving via `textwrap` + unicode-width; `wrap_ranges_trim` returns byte ranges per wrapped row (`.../pager-render/src/render/wrapping.rs:12`); highlight mapping is display-column based (`byte_range_to_row_cols`, `:46`).
- Scroll input: crossterm `MouseEventKind::ScrollUp/Down` → `Action::ScrollUp/Down(n)` (`app/actions.rs:279`; dispatch in `app/dispatch/router.rs:568`) → `scroll_lines(n, items)` (`methods.rs:975`). Lines-per-tick default 3 (`[ui].scroll_lines`; `settings/defs.rs:1049`; registry default 3 at `registry.rs:525`); override via `GROK_SCROLL_LINES` env (`pager-render/src/appearance/cache.rs:554`). Keyboard: page/half-page/goto-top/bottom, selection-anchored (`router.rs:555+`). Rapid wheel events coalesced in tests at 4ms/12ms/40ms spacings (`event_loop.rs:5390+`); key bursts coalesced by `coalesce_rapid_keys` with `PASTE_DETECT_TIMEOUT = 2ms` (`:3459`).
- Ratatui: used in both `xai-grok-pager` and `xai-grok-pager-render` (+ `xai-ratatui-inline`, `xai-ratatui-textarea` forks); `terminal.viewport_area()` / `set_viewport_area(Rect)` (`event_loop.rs:742`); immediate `terminal.clear()` + overlay reset only on `force_full_repaint` (`present_if_dirty`, `:616`).
- ptyctl: headless PTY controller on `alacritty_terminal` (spawn, keystrokes, screen scrape, HTTP REST) — `crates/codegen/ptyctl/src/lib.rs:1`. Test/harness tooling, NOT on the TUI render path.
- Misc caps: thought width 40..500 (`settings/defs.rs:19`); picker choices bounded by `MAX_PICKER_CHOICES` (`registry.rs:1661`); agent collapsed view `AUTO_COMPACT_MAX_ROWS = 20` (`views/agent.rs:97`); clipboard image cap `MAX_WRAP_IMAGE_BYTES = 20MB` (`wrap_clipboard_image.rs:22`).

## Details — agent/provider abstraction

- No provider trait: `grep "pub trait"` over `xai-grok-agent`, `xai-grok-models`, `xai-grok-config-types`, `xai-agent-lifecycle` finds only lifecycle *contributors* (`LocalTurnInputContributor`, `LocalCommandContributor`, `LocalSessionLifecycleContributor`, `TurnInputContributor`, `CommandContributor`, `SessionLifecycleContributor`, `TurnLifecycleContributor: Send + Sync` at `xai-agent-lifecycle/src/send/contributors/turn_lifecycle.rs:170`, hooks `on_turn_start/on_turn_done/on_turn_abort/on_turn_error`).
- Session→model binding: per-session `SamplingConfig` (`crates/codegen/xai-grok-sampling-types/src/types.rs:1075`): `base_url`, `model`, `api_backend: ApiBackend`, `max_completion_tokens`, `temperature`, `top_p`, `max_retries`, `rate_limit_retry_threshold`, `reasoning_effort/summary`, `stream_tool_calls`, `extra_headers`/`query_params`/`env_http_headers` (BYOK), `context_window`, `conversation_group_id` (survives model changes). Held opaquely by `xai-chat-state` (`types.rs:23,32`; "actor stores and returns them — it never interprets them", `:109`).
- Wire-protocol enum: `ApiBackend { ChatCompletions (default), Responses, Messages }` (`types.rs:1019`); `supports_native_schema()` (`:1032`). Sampler has per-backend stream parsers (`xai-grok-sampler/src/stream/{responses,chat_completions,messages}.rs`; `stream_responses`, `responses.rs:192`, chunk-indexed SSE telemetry).
- Model catalog: `xai-grok-models/default_models.json` (default + `web_search`/`image_description`/`session_summary` role models + `models[]` list), embedded via `DEFAULT_MODELS_JSON` (`models/src/lib.rs:13`); precedence CLI flag → env → config.toml → remote → defaults (`:4`). Subagents: frontmatter `model: "<id>" | inherit | omitted → ModelOverride::{Override,Inherit}` (`xai-grok-agent/src/config.rs:541,759`).
- No CLI shell-out: no `codex exec`-style subprocess agent invocation in `xai-grok-agent`/`xai-grok-sampler` (grep negative). HTTP via `shared_http` (+mTLS) in sampler.
- ACP = in-process bus: `AcpChannel` = tokio mpsc pair, `acp_channels()` linked pair, `acp_send` request/response via oneshot (`xai-acp-lib/src/channel.rs:13`); gateways `AcpGatewaySender/Receiver` with `forward_with_completion` / `forward_fire_and_forget` (`gateway.rs:336,350`); message traits `AcpSide/AcpMethod/AcpRequest` (`message.rs:16,44,49`); stdio line transport exists (`stdin_reader`, `line_reader`) for external ACP peers, but the TUI loop consumes ACP events over channels.

## Adoption candidates for polyforge (perf impact vs effort)

1. **Dirty-flag + min-draw-interval throttle (high impact, low effort)** — gate Ratatui draws behind `dirty + in_flight + 16ms throttle`; single biggest streaming-jank fix. See `event_loop.rs:497-630`, `display_refresh_startup.rs`.
2. **Virtualized transcript: stable IDs + per-width height cache + visible-map (high impact, medium effort)** — only lay out/render the viewport; invalidate cache on width change. See `list_pane/state/methods.rs`, `render/wrapping.rs`.
3. **Writer thread / non-blocking terminal writes (medium-high impact, medium effort)** — never block the event loop on a slow terminal; add stall detection (5s warn). See `pager-render/src/render/draw.rs:150-260`.
4. **Input/event coalescing + channel priority (medium impact, low effort)** — coalesce wheel/key bursts; service low-priority channels last so input/ACP can't starve. See `coalesce_rapid_keys` (`:3612`), 128-slot voice comment (`:2923`).
5. **`SamplingConfig`-style per-session binding + backend enum (structural, medium effort)** — replace ad-hoc `muse serve` coupling with a serializable session config + transport enum; makes future providers additive, not invasive. See `sampling-types/src/types.rs:1019-1115`.
6. **Contributor-style lifecycle hooks (low priority)** — only if polyforge grows plugins; do not copy the contributor system prematurely.
